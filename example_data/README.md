(converted losslessly from the original TIFFs). Used by `Pipeline_Demo.ipynb`.

| File | Channel |
|---|---|
| `DAPI.png` | nuclei |
| `HLADR.png`, `CD44.png`, `CD3.png`, `CD11c.png`, `Vimentin.png`, `PlasmaCell.png`, `CD20Cytoplasmic.png` | markers |
